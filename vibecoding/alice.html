3. Циклы и условия

Цикл for используется для перебора последовательностей, while — пока условие истинно. Условие if/elif/else управляет ветвлением.

numbers = [1, 2, 3, 4, 5]
for n in numbers:
    if n % 2 == 0:
        print(f"{n} — чётное")
    else:
        print(f"{n} — нечётное")

4. Функции

Функция — это блок кода, который можно вызывать многократно. Она может принимать аргументы и возвращать результат.

def greet(name, greeting="Привет"):
    return f"{greeting}, {name}!"

message = greet("Bob")
print(message)  # Привет, Bob!

Задание 4: Напиши функцию square(x), которая возвращает квадрат числа x. Вызови её для числа 7 и выведи результат.



5. Файлы и модули

Для работы с файлами используется конструкция with open(...). Она гарантирует корректное закрытие файла.

with open("data.txt", "w", encoding="utf-8") as f:
    f.write("Привет, мир!")

with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)

Модули позволяют разбивать код на логические части. Например, import math.
